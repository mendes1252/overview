# 🛒 WhatsApp Legend Generator - Afiliado Amazon & Shopee

Um aplicativo local poderoso para gerar legendas de vendas de alta conversão para WhatsApp, utilizando IA rodando no seu próprio computador (Ollama).

## 🚀 Funcionalidades

- **100% Local e Gratuito**: Sem APIs pagas, seus dados não saem do seu PC.
- **Copywriting Especializado**: Prompt otimizado para gatilhos mentais de venda (urgência, escassez, prova social).
- **Multi-Plataforma**: Detecta automaticamente links da Amazon e Shopee.
- **Histórico Local**: Salva suas gerações em um arquivo JSON para reutilização.
- **Integração WhatsApp**: Botão direto para abrir o app com a legenda preenchida.

## 📋 Pré-requisitos

1. **Python 3.10+** instalado.
2. **Ollama** instalado e rodando.
   - Baixe em: [https://ollama.com](https://ollama.com)
   - Instale um modelo (recomendado): `ollama run llama3` ou `ollama run mistral`
